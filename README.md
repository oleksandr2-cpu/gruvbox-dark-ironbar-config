this guide created for arch linux

Install guide:
download ironbar(if you dont have it)

paru -S ironbar

create a config directory(if you dont have it):

mkdir -p /home/your username/.config/ironbar

download my config.corn and style.css and move this files to ironbar folder:

cd downloads(or another folder where locates this files)

mv config.corn style.css /home/your username/.config/ironbar

relogin in your system

start ironbar:

ironbar
